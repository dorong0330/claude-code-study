## 🗓️ 학습 기간

- 2026.10.27 ~ 2026.11.23 (4주)
- 평일 하루 1~1.5시간, 주말 복습 및 정리

| 주차 | 주제 | 산출물 |

| 4주 | 프롬프트/컨텍스트 엔지니어링 · SDD · 하네스 · 배포 자동화 | 최종 프로젝트 + CI |
