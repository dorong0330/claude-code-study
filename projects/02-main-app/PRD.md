# PRD — 지원 현황 트래커

> 상태: 초안 · 작성일 2026-11-19

## 1. 문제 정의
- 여러 회사에 지원하다 보면 어디에 지원했고 지금 어느 단계인지 헷갈린다
- 한 페이지에서 지원 목록과 단계별 현황을 보면 다음 할 일을 바로 알 수 있다

## 2. 대상 사용자
- 1차: 나 자신 (백엔드 취업 준비)
- 확장: 백엔드 신입 준비생

## 3. 핵심 기능 (MVP)

| # | 기능 | 설명 |
|---|---|---|
| F1 | 지원 추가 | 회사명, 직무, 지원일, 공고 링크, 메모를 입력해 목록에 추가 |
| F2 | 상태 변경 | 항목마다 상태를 선택 |
| F3 | 현황 요약 | 상태별 개수를 Chart.js 차트로 표시 |
| F4 | 상태 추가 | 기본 상태 외에 내 상태(예: 코딩 테스트)를 추가 |

- 기본 상태: 지원 → 서류 합격 → 면접 → 최종 합격 / 불합격 (삭제 불가)
- 사용 중인 사용자 상태는 삭제할 수 없다 (항목의 상태가 사라지는 것 방지)
- 삭제: 잘못 넣은 지원 항목을 지울 수 있어야 한다
- 데이터는 브라우저 `localStorage`에 저장 (새로고침해도 유지)

## 4. 범위 밖 (MVP에서 하지 않음)
- 로그인, 서버, DB
- 여러 기기 동기화
- 마감일 알림
- 공고 자동 수집

## 5. 기술 스택
- HTML / CSS / JavaScript (프레임워크 없음, 1주차 링크 페이지와 같은 구성)
- 차트: Chart.js (CDN)
- 저장: `localStorage`
- UI는 최소한으로 둔다 (프론트는 관심 분야가 아님, 기능 동작이 우선)

## 6. 완료 기준
- [ ] 지원 항목을 추가·상태 변경·삭제할 수 있다
- [ ] 메모를 입력하고 다시 볼 수 있다
- [ ] 사용자 상태를 추가하면 선택지와 차트에 반영된다
- [ ] 새로고침 후에도 데이터가 남아 있다
- [ ] 첫 화면에서 상태별 개수가 차트로 보인다

## 7. 향후 확장 (MVP 이후)
- `localStorage` 대신 Spring Boot REST API + DB로 저장소 교체 (백엔드 학습용)
